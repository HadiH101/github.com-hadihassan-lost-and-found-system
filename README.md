# Lost and Found System

A database management system project built using PHP, MySQL, HTML and CSS.

## Features

- User Registration and Login
- Admin Role System
- Category Management
- Item Management
- Reports System
- Claims System
- Claim Approval/Rejection
- Search Functionality

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP

## How to Run

1. Start Apache and MySQL in XAMPP
2. Place project inside htdocs
3. Import SQL database
4. Open localhost project URL
